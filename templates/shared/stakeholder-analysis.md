# Stakeholder Analysis Template

> **🚧 Content In Progress**

## Purpose
Map stakeholders, understand their concerns, and tailor messaging for FDE transformation.

## When to Use
- At the start of FDE transformation
- When driving organizational change
- When facing resistance

## Template Structure

| Stakeholder | Role | Support Level | Key Concerns | Tailored Messaging | Action Items |
|-------------|------|---------------|--------------|-------------------|--------------|
| [Name] | VP Engineering | Supporter | Code quality | FDEs follow same standards | Involve in hiring |
| [Name] | Product Lead | Skeptic | Resource drain | FDEs accelerate feedback | Joint success metrics |
| [Add more...] | | | | | |

### Support Levels
- **Champion**: Actively advocates
- **Supporter**: Positive but passive
- **Neutral**: No strong opinion
- **Skeptic**: Concerned but open
- **Blocker**: Actively resists
