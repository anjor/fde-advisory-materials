# RACI Matrix Template

> **🚧 Content In Progress**

## Purpose
Define clear responsibilities across FDE, Product, Platform, and Commercial teams.

## When to Use
- When defining org structure
- When clarifying team interfaces
- When resolving ownership conflicts

## RACI Definitions
- **R** = Responsible (does the work)
- **A** = Accountable (final decision maker)
- **C** = Consulted (provides input)
- **I** = Informed (kept in the loop)

## Template Structure

| Activity/Decision | FDE Team | Product Team | Platform Team | Commercial Team |
|-------------------|----------|--------------|---------------|-----------------|
| Client requirement gathering | R/A | C | I | I |
| Product roadmap prioritization | C | R/A | C | C |
| Platform feature development | C | C | R/A | I |
| Client deployment | R/A | C | C | I |
