# FDE Metrics Dashboard Specification

> **🚧 Content In Progress**

## Purpose
Define key metrics and dashboard structure for tracking FDE performance.

## When to Use
- When establishing FDE metrics program
- When building reporting dashboards
- When evaluating FDE effectiveness

## Dashboard Structure

### Organizational Metrics
- Number of active deployments
- Revenue per FDE
- Time-to-deployment (average)
- Feature reuse rate
- Customer outcome achievement

### Individual Metrics
- Deployments per FDE
- Customer satisfaction scores
- Revenue contribution
- Platform contributions

### Health Metrics
- FDE burnout indicators
- Rotation cadence
- Client health scores
- At-risk account flags
