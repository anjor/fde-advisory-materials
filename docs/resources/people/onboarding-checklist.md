# 90-Day FDE Onboarding Checklist

> **🚧 Content In Progress**

## Purpose
Structured 90-day onboarding program ensuring new FDEs ramp effectively.

## When to Use
- For every new FDE hire
- As a guide for onboarding buddies/mentors
- For tracking onboarding progress

## Program Structure

### Week 1: Orientation
- [ ] Tools and access setup
- [ ] Culture and team introductions
- [ ] Product overview

### Weeks 2-4: Shadowing
- [ ] Shadow active FDE engagements
- [ ] Observe client meetings
- [ ] Review past deployments

### Weeks 5-8: Supported First Deployment
- [ ] Take on first project with mentor
- [ ] Lead client meetings with support
- [ ] Checkpoint reviews

### Weeks 9-12: Independent Work
- [ ] Independent deployment
- [ ] Regular check-ins
- [ ] 90-day review
